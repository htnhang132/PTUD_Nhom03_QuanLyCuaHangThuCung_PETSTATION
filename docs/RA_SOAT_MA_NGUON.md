# Rà soát từng file Pet Station

Ngày 24/11/2026. Phạm vi đã chọn: **dọn và chuẩn hóa an toàn**, giữ tên tiếng Việt không dấu, giữ hành vi. Báo cáo phân biệt bằng chứng tĩnh và kiểm thử, không tuyên bố đã kiểm chứng thủ công mọi nhánh của mọi file.

## Kết luận và tiêu chí

- Trước dọn: 297 file Java chính, 24 file Java test. Sau gộp tiện ích: **296 file Java chính**, **25 file Java test** (có thêm kiểm tra tài liệu).
- Mọi file nguồn chính có nơi tham chiếu trong Java hoặc là entrypoint App. Đây là bằng chứng để **giữ**, không phải chứng nhận toàn bộ phương thức đều được dùng hoặc SOLID hoàn toàn. Không xóa lớp từ kết quả grep đơn lẻ.
- Không thấy file Java/resource trùng nội dung hoàn toàn trong lần quét. Getter/setter và enum giống cấu trúc không tự động là code thừa.
- Dọn đã chốt: gộp TruongDanhMuc vào DinhDang/VaiTro; thay BieuMauPanel bằng factory không kế thừa Swing; sửa comment sai; chuẩn hóa tài liệu và liên kết.
- Giữ các lớp lớn, facade, adapter mảng và constructor/macDinh hiện có; ghi hạn chế từng file dưới đây. Những việc tách panel lớn, chuyển package GioHang, thay toàn bộ mảng bằng DTO không thuộc đợt dọn này.
- Chuẩn áp dụng: [CHUAN_CODE.md](CHUAN_CODE.md). “Giữ” nghĩa là chưa có lý do an toàn để xóa/gộp, không đồng nghĩa mọi thiết kế đã tối ưu.

### Đánh giá OOP và hướng sự kiện sau sửa

Phân tầng GUI → Service → DAO đã rõ hơn; DTO mới hạn chế mảng vị trí ở phần được sửa. Giao dịch và kiểm tra quyền nằm ở service, SQL ở DAO; SwingWorker giữ truy vấn ghi ra khỏi EDT trong các luồng danh mục đã xử lý. Observer có cô lập lỗi và thông báo sau commit.

Chưa thể kết luận “chuẩn OOP hoàn toàn”: nhiều panel vẫn quá lớn, danh mục còn dùng mảng vị trí, model có setter rộng, khởi tạo service mặc định/static còn phổ biến. Adapter `CacDong` vẫn cho UI sửa phần tử vì tương thích. Cần refactor từng phân hệ cùng regression, ưu tiên `QuanLyDanhMucPanel`, `LapPhieuSpaPanel`, `NghiepVuSpaPanel`; không gộp các nghiệp vụ khác nhau chỉ vì giao diện giống nhau.

Hướng sự kiện hiện là Swing event + Observer trong cùng tiến trình, không phải kiến trúc event sourcing. Chưa có hàng đợi bền vững/outbox cho thông báo sau commit; log lỗi không đồng nghĩa có cơ chế tự gửi lại. Chưa có kiểm thử tải nhiều máy thu ngân đồng thời, sự cố mất mạng giữa chừng, DPI/máy in/QR thật hay kiểm thử xâm nhập.
